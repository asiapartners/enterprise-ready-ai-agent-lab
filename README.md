# Enterprise-Ready AI Agent Lab
*Combining Intelligence and Governance for business-ready AI coworkers*

This hands-on lab will teach you how to build autonomous AI assistants deployed on user-managed hardware, how to connect the assistant to key tools and define its harness or capability perimeter, and how to govern the agent through Microsoft Agent 365.

### What You'll Learn
- Setting up an AI assistant (OpenClaw) on your hardware
- Connecting communication channels (Teams)
- Creating agent personality and capabilities
- Building and executing tools
- Defining capability perimeters
- Agent governance via Agent 365

## Lab Structure

### [Phase 1: Build Your Autonomous AI Assistant](./phase-1-building-autonomous-ai-assistant/)
- **Duration**: 1-2 hours
- **Focus**: Core agent architecture and capabilities

### Phase 2: Tool Integration & Capability Perimeters (Coming)
- Integrating external tools and APIs

### Phase 3: Multi-Agent Orchestration & Governance (Coming)
- Building multi-agent systems
- Enterprise monitoring and logging
- Microsoft Agent 365 integration
- Advanced compliance and security

## Technologies & Frameworks

This lab uses:
- **Node.js** - Runtime for gateway and agent coordination
- **OpenClaw** - Personal AI assistant deployed on a Windows Azure VM
- **Azure OpenAI** - LLM Provider
- **Microsoft Teams** - External Communication Platform
